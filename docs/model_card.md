# Model card: synthetic HbA1c regression benchmark

**Model version:** `synthetic-hba1c-ridge-v0.1.0`
**Status:** Trained and evaluated on project-generated synthetic data only.

## Intended use

This artifact demonstrates an end-to-end, local regression pipeline over a
synthetic patient-linked clinical and wearable-like dataset. It estimates the
generated `synthetic_future_hba1c_percent` target 90 days after a synthetic
prediction timestamp.

It is not a laboratory measurement, clinical prediction model, diagnosis,
treatment recommendation, or medical device. It must not be used for patient
care, risk scoring, or claims about real-world HbA1c prediction.

## Data and target

- 40 project-generated synthetic patients, seed `20261012`.
- Patient-disjoint split: 28 training, 6 validation, and 6 held-out test
  patients.
- The target is generated by the documented formula in
  [data_provenance.md](data_provenance.md); it is not observed laboratory data.
- Source records comprise three synthetic clinical observations and 14 daily
  wearable-like records per patient.
- No future-event/deterioration classifier exists or is implied by this model.

## Training procedure

Two deterministic scikit-learn `StandardScaler` + `Ridge(alpha=1.0)` pipelines
were fitted on `train.csv` only:

| Candidate | Features |
| --- | --- |
| Clinical-only baseline | Age, synthetic diabetes-history duration, latest synthetic HbA1c, fasting glucose, and BMI. |
| Clinical plus wearable | All clinical baseline features plus 14-day means for steps, active minutes, resting heart rate, sleep duration, and sleep consistency. |

The candidate with the lowest validation MAE was selected. The test split did
not influence fitting or selection. The selected artifact includes its scaler,
Ridge model, feature list, split patient IDs, and version metadata.

## Measured results

| Candidate | Validation MAE | Validation RMSE | Held-out test MAE | Held-out test RMSE |
| --- | ---: | ---: | ---: | ---: |
| Clinical-only Ridge | 0.231 | 0.272 | 0.149 | 0.174 |
| Clinical-plus-wearable Ridge | 0.206 | 0.246 | 0.142 | 0.159 |

The clinical-plus-wearable model was selected by validation MAE. Exact
unrounded results are written by the training command to
`models/synthetic_hba1c_metrics.json`.

## Explanations

The API and dashboard explain each prediction using **exact linear feature
contributions**: for the saved `StandardScaler` + `Ridge` pipeline, each
feature's contribution is `coefficient × scaled_feature_value`, plus the model
intercept. Because the model is linear, these contributions reconstruct the
estimate exactly (verified by test
`test_prediction_explanation_contributions_sum_to_the_estimate`), so the
explanation is model arithmetic rather than an approximation. The dashboard
labels it as such: it describes how the synthetic model produced its number,
not clinical causation.

**SHAP (Shapley Additive Explanations) was considered and deliberately not
added.** For a linear model, SHAP's `LinearExplainer` values reduce to the
same coefficient-based attributions already computed exactly here, so SHAP
would add a heavy dependency chain without changing any reported number. The
project instructions allow "SHAP or another explanation method … if it can be
applied correctly"; the exactly-reconstructing method above is the other
explanation method. If a non-linear model is adopted later, its explainer must
be chosen then and this section updated.

## Limitations and risks

- This evaluation contains six held-out synthetic patients and is not a stable
  estimate of real-world performance.
- The target mechanism is known to the generator, so learning it does not
  validate clinical relationships or causal effects of activity, heart rate, or
  sleep.
- The model does not return calibrated uncertainty, a deterioration probability,
  or a treatment recommendation.
- Real deployment would require appropriately governed, representative,
  patient-linked data; clinical validation; bias assessment; calibration; and
  clinical/regulatory review.
